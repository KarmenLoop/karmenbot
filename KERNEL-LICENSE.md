# Koder 内核许可协议（草稿，待法务审定）

适用对象：karmenbot 从官网下载、安装到 `vendor/` 目录的 Koder 内核文件（以下简称“内核”）。
karmenbot 本身的开源代码不适用本协议，见 `LICENSE`。

1. **可以做的**：个人和企业可以免费下载、安装内核，并把它与 karmenbot 一起运行和使用，包括商业用途。
2. **不可以做的**：未经书面许可，不得
   - 单独复制、分发、转售、出租或再授权内核；
   - 修改内核，或基于内核制作衍生作品；
   - 对内核进行反编译、反混淆或其他逆向工程（适用法律明确允许的除外）；
   - 把内核用在 karmenbot 以外的软件中；
   - 移除或修改内核中的版权与许可声明。
3. **随 karmenbot 一起转发**：只要按原样转发官网提供的内核包（含本协议、校验值不变），可以随 karmenbot 的副本一起提供。
4. **所有权**：内核的著作权及其他知识产权归 Koder 所有。本协议只授予上述使用权，不转让任何权利。
5. **免责**：内核按“现状”提供，不作任何明示或默示保证；在法律允许的最大范围内，Koder 不对使用内核造成的任何损失负责。
6. **终止**：违反本协议的，授权自动终止，须删除所有内核副本。
