# Demo read-only skill

A safe example pack shipped with karmenbot. It only contains instructional steps — no shell, network, or file writes.

## Steps

1. Confirm you are in the intended workspace folder.
2. Tell the user this skill is read-only and will not change files.
3. Suggest `karmenbot skill list` to see other installed packs.

## Notes

Permissions are all false. The scanner should pass. Use this as a template for new skills.
